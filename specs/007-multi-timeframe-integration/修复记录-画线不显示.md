# 修复记录：多周期模式下画线不显示

## 问题

多周期显示模式下，画线下单的挂单线、止损线、止盈线都不显示。

## 诊断

### 可能的原因

1. **vt_symbol 未正确设置**: `ChartWidget` 的 `_vt_symbol` 属性为空或格式不对
2. **main_engine 未正确设置**: `DrawingOrderController` 的 `_main_engine` 为空
3. **价格线添加到错误的图表**: 价格线可能被添加到单周期图表而不是多周期图表
4. **DrawingOrderController 未正确初始化**: controller 可能为 None

## 修复措施

### 修复1: 添加详细调试日志

在以下位置添加了详细的日志输出：

#### 位置1: `MultiTimeframeWidget.enable_drawing_order()`

```python
def enable_drawing_order(self, main_engine, vt_symbol, on_drawing_click):
    print(f"\n[MultiTimeframeWidget] enable_drawing_order 被调用:")
    print(f"  main_engine: {main_engine}")
    print(f"  vt_symbol: {vt_symbol}")  # 检查传入的值
    print(f"  _chart: {self._chart}")
    
    # 设置并验证
    self._chart.set_main_engine(main_engine)
    self._chart.set_vt_symbol(vt_symbol)
    
    controller = self._chart.get_drawing_order_controller()
    if controller:
        print(f"  controller._vt_symbol: {getattr(controller, '_vt_symbol', 'NOT SET')}")
        print(f"  controller._main_engine: {getattr(controller, '_main_engine', 'NOT SET')}")
```

#### 位置2: `ChartWindow.toggle_drawing_mode()`

```python
def toggle_drawing_mode(self):
    if self.display_mode == "multi":
        chart = self.multi_timeframe_widget._chart
        
        # 重新确保设置了参数
        chart.set_main_engine(self.main_engine)
        chart.set_vt_symbol(self.current_vt_symbol)
        
        controller = chart.get_drawing_order_controller()
        if controller:
            # 确保 controller 也设置了参数
            controller.set_vt_symbol(self.current_vt_symbol)
            controller.set_main_engine(self.main_engine)
```

### 修复2: 在 toggle_drawing_mode 中重新设置参数

**问题**: 即使在 `enable_drawing_order()` 中设置了参数，但如果后续有任何重置操作，参数可能会丢失。

**解决**: 每次切换画线模式时，重新设置 `vt_symbol` 和 `main_engine`，确保参数正确。

### 修复3: 确保调用顺序正确

**正确的调用顺序**:

1. 加载数据（单周期模式）
2. 切换到多周期模式
   - 调用 `sync_data_to_multi_timeframe()`
   - 调用 `enable_realtime()`
   - 调用 `enable_drawing_order()`  ← 设置画线交易参数
3. 点击"画线下单"按钮
   - 调用 `toggle_drawing_mode()`  ← 启用画线模式
   - 重新设置参数（确保正确）

## 如果日志显示参数未设置

### 问题: controller._vt_symbol 显示 'NOT SET'

**原因**: 
1. `ChartWidget.set_vt_symbol()` 未被调用
2. 或者调用后又被清空了

**解决**: 
- 检查 `enable_drawing_order()` 是否被正确调用
- 检查 `switch_symbol()` 是否会清空 vt_symbol

### 问题: controller._main_engine 显示 'NOT SET'

**原因**: 
1. `ChartWidget.set_main_engine()` 未被调用
2. 或者调用后又被清空了

**解决**: 
- 检查 `enable_drawing_order()` 是否被正确调用
- 确保 `self.main_engine` 不为 None

## 如果画线没有任何反应

### 检查1: 画线模式是否启用

```python
controller = chart.get_drawing_order_controller()
print(f"画线模式是否启用: {controller.is_enabled() if controller else False}")
```

### 检查2: 鼠标事件是否被捕获

可能的问题：
- 多周期 Widget 的事件被其他组件拦截
- 图表的 z-order 不正确

### 检查3: 价格线管理器

```python
manager = chart._price_line_manager
print(f"价格线管理器: {manager}")

```
