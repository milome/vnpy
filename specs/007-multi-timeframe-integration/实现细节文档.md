# 多周期Widget整合到ChartWindow实现细节文档

## 一、概述

本文档详细记录了多周期K线显示功能整合到 `ChartWindow` 的实现细节，包括架构设计、核心组件、数据流、关键方法等。

## 二、架构设计

### 2.1 模式切换方案（方案A）

采用**模式切换**方案，在 `ChartWindow` 中添加"单周期模式"和"多周期叠加模式"的切换选项。

**核心设计原则：**
- 保持现有单周期模式功能完整
- 代码隔离性好，维护方便
- 两种模式共享相同的数据源和事件系统
- 可以逐步迁移用户

### 2.2 核心组件

#### 2.2.1 ChartWindow 扩展

**位置**: `vnpy/trader/ui/widget.py`

**关键属性**:
```python
# 显示模式：单周期或多周期叠加
```

## 三、数据流

### 3.1 历史数据加载流程

1. **单周期模式**:
   ```
   ChartWindow.load_history_data()
   → ChartWindow.process_history_data()
   → ChartWidget.update_history()
   ```

2. **多周期模式**:
   ```
   ChartWindow.load_history_data()
   → ChartWindow.process_history_data()
   → ChartWindow.sync_data_to_multi_timeframe()
   → MultiTimeframeWidget._load_history_data()
   → 各周期 BarManager 加载数据
   → CrossIndexCandleItem 绘制
   ```

### 3.2 实时更新流程

1. **单周期模式**:
   ```
   Tick Event
   → ChartWindow.process_tick_event()
   → BarGenerator.on_tick()
   → ChartWidget.update_bar()
   ```

2. **多周期模式**:
   ```
   Tick Event
   → ChartWindow.process_tick_event()
   → MultiTimeframeWidget.update_tick()
   → BarGenerator (1m).on_tick()
   → _on_1m_bar() → BarGenerator (5m).update_bar()
   → _on_5m_bar() → BarGenerator (1h).update_bar()
   → _on_1h_bar() → BarGenerator (4h).update_bar()
   → _on_4h_bar() → 各周期 BarManager 更新
   → CrossIndexCandleItem 更新绘制
   ```

### 3.3 模式切换流程

```
用户选择模式
→ ChartWindow.switch_display_mode()
→ _switch_to_single_timeframe_mode() 或 _switch_to_multi_timeframe_mode()
→ 隐藏/显示相应的 Widget
→ 同步数据（如果需要）
→ 更新控制面板可见性
```

## 四、关键实现细节

### 4.1 模式切换实现

**文件**: `vnpy/trader/ui/widget.py`

**关键代码**:
```python
def switch_display_mode(self, mode: str) -> None:
    """切换显示模式"""
    if mode == self.display_mode:
        return
    
    if mode == "single":
        self._switch_to_single_timeframe_mode()
    else:
        self._switch_to_multi_timeframe_mode()
    
    self.display_mode = mode
    self.on_mode_changed()

def _switch_to_multi_timeframe_mode(self) -> None:
    """切换到多周期模式"""
    # 隐藏单周期图表
    if self.chart:
        self.chart.setVisible(False)
    
    # 显示多周期Widget
    if self.multi_timeframe_widget:
        self.multi_timeframe_widget.setVisible(True)
        # 同步数据
        self.sync_data_to_multi_timeframe()
        # 启用实时更新
        self.multi_timeframe_widget.enable_realtime()
        # 启用画线交易功能
        self.multi_timeframe_widget.enable_drawing_order(
            main_engine=self.main_engine,
            vt_symbol=self.current_vt_symbol
        )
```

### 4.2 实时更新实现

**文件**: `vnpy/chart/multi_timeframe_widget.py`

**关键代码**:
```python
def enable_realtime(self) -> None:
    """启用实时更新"""
    if self._realtime_enabled:
        return
    
    # 创建 BarGenerator 实例
    self._bg_1m = BarGenerator(self._on_1m_bar)
    self._bg_5m = BarGenerator(self._on_5m_bar)
    self._bg_1h = BarGenerator(self._on_1h_bar)
    self._bg_4h = BarGenerator(self._on_4h_bar)
    
    self._realtime_enabled = True

def update_tick(self, tick: TickData) -> None:
    """处理tick数据更新"""
    if not self._realtime_enabled:
        return
    
    # 只处理1m BarGenerator，其他周期通过回调链式更新
    if self._bg_1m:
        self._bg_1m.update_tick(tick)
```

### 4.3 合约切换实现

**文件**: `vnpy/chart/multi_timeframe_widget.py`

**关键代码**:
```python
def switch_symbol(
    self,
    vt_symbol: str,
    start: datetime,
    end: datetime
) -> None:
    """切换合约"""
    # 清理现有数据
    self._cleanup_data()
    
    # 重新初始化 BarGenerator
    self._reinitialize_bar_generators()
    
    # 加载新合约的历史数据
    self._load_history_data(vt_symbol, start, end)
```

### 4.4 画线交易功能集成

**文件**: `vnpy/chart/multi_timeframe_widget.py`

**关键代码**:
```python
def enable_drawing_order(
    self,
    main_engine: MainEngine,
    vt_symbol: str
) -> None:
    """启用画线交易功能"""
    if not self._chart:
        return
    
    # 配置 ChartWidget 的画线交易功能
    self._chart.set_main_engine(main_engine)
    self._chart.set_vt_symbol(vt_symbol)
    self._chart.set_drawing_click_callback(self._on_drawing_click)
```

## 六、性能指标

### 6.1 性能目标

- **模式切换性能**: < 500ms
- **大数据量加载性能**: < 5s
- **实时更新延迟**: < 100ms
- **内存使用**: < 300MB

### 6.2 性能优化

1. **数据复用**: 模式切换时复用已加载的数据
2. **延迟加载**: MultiTimeframeWidget 延迟初始化
3. **缓存机制**: 使用缓存减少重复计算

## 七、使用示例

### 7.1 基本使用

```python
from vnpy.trader.ui.widget import ChartWindow
from vnpy.trader.engine import MainEngine, EventEngine

# 创建 ChartWindow
main_engine = MainEngine()
event_engine = EventEngine()
chart_window = ChartWindow(main_engine, event_engine)

# 切换到多周期模式
chart_window.switch_display_mode("multi")

# 切换合约
chart_window.current_vt_symbol = "MHImain.HKFE"
chart_window.switch_chart()

# 打开设置对话框
chart_window.show_multi_timeframe_settings()
```

## 八、已知问题和限制

### 8.1 已知问题

1. **Qt 信号断开警告**: 在测试环境中可能出现 `Failed to disconnect` 警告，不影响功能
2. **内存使用**: 加载大量历史数据时内存使用可能较高

### 8.2 限制

1. **数据源**: 目前主要支持从数据库加载历史数据
2. **交易所**: 主要测试和优化针对 HKFE 交易所
3. **周期**: 默认支持 1m/5m/1H/4H，其他周期需要扩展
