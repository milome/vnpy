# 多周期K线显示功能使用指南

## 一、功能概述

多周期K线显示功能允许你在同一张图表上同时查看多个时间周期的K线（1分钟、5分钟、1小时、4小时），方便进行多时间框架分析和交易决策。

## 二、如何切换到多周期模式

### 2.1 打开K线图表窗口

1. 启动 VeighNa Trader
2. 连接交易网关
3. 在主界面点击"K线图表"按钮，打开 ChartWindow

### 2.2 切换显示模式

在 ChartWindow 窗口顶部，你会看到一个**"显示模式"下拉框**：

```
┌─────────────────────────────────────────┐
│ 合约: MHImain.HKFE  [显示模式: ▼]        │
│ ┌──────────┐  ┌──────────┐              │
│ │ 单周期   │  │ 画线下单 │              │
│ │ 多周期 ← │  └──────────┘              │
│ └──────────┘                             │
│                                          │
│  [K线图表区域]                           │
│                                          │
└─────────────────────────────────────────┘
```

**操作步骤**：
1. 点击"显示模式"下拉框
2. 选择"**多周期**"选项
3. 图表会自动切换到多周期叠加显示模式

### 2.3 界面变化

切换到多周期模式后，界面会发生以下变化：

#### 变化1: 周期选择框隐藏
- 单周期模式下的"周期选择"下拉框（1m/5m/1H等）会被隐藏
- 因为多周期模式会同时显示所有周期

#### 变化2: 多周期设置按钮显示
- 出现"**多周期设置**"按钮
- 点击可以调整各周期K线的显示设置

```
┌─────────────────────────────────────────┐
│ 合约: MHImain.HKFE  显示模式: 多周期     │
│ ┌──────────────┐  ┌──────────┐          │
│ │ 多周期设置   │  │ 画线下单 │          │
│ └──────────────┘  └──────────┘          │
│ （周期选择框已隐藏）                     │
│                                          │
│  [多周期K线叠加显示区域]                 │
│  - 青色填充: 1分钟K线（基准）            │
│  - 蓝色粗线: 5分钟K线                    │
│  - 黄色粗线: 1小时K线                    │
│  - 红色粗线: 4小时K线                    │
│                                          │
└─────────────────────────────────────────┘
```

#### 变化3: K线显示方式
- **1分钟K线**: 青色填充的传统蜡烛图（作为基准时间轴）
- **5分钟K线**: 蓝色粗线，跨越5个1分钟位置
- **1小时K线**: 黄色粗线，跨越60个1分钟位置
- **4小时K线**: 红色粗线，跨越240个1分钟位置

所有大周期K线都对齐到1分钟时间轴上。

## 三、多周期设置

### 3.1 打开设置对话框

点击"**多周期设置**"按钮，打开设置对话框：

```
┌─────────────────────────────────────┐
│  多周期K线显示设置                   │
├─────────────────────────────────────┤
│                                     │
│  ☑ 显示 5分钟K线                    │
│     透明度: [████████░░] 80%        │
│                                     │
│  ☑ 显示 1小时K线                    │
│     透明度: [████████░░] 80%        │
│                                     │
│  ☑ 显示 4小时K线                    │
│     透明度: [████████░░] 80%        │
│                                     │
│  ┌────────┐  ┌────────┐            │
│  │ 预览   │  │ 应用   │            │
│  └────────┘  └────────┘            │
└─────────────────────────────────────┘
```

### 3.2 调整显示设置

**显示/隐藏周期**:
- 勾选/取消勾选复选框可以显示/隐藏对应周期的K线
- 至少需要保持一个周期显示

**调整透明度**:
- 拖动滑块调整阴线填充的透明度
- 0% = 完全不透明
- 100% = 完全透明
- 建议值：80-95%

**预览和应用**:
- 点击"**预览**"按钮可以实时查看效果
- 点击"**应用**"按钮保存设置并关闭对话框

## 四、在多周期模式下使用其他功能

### 4.1 画线下单

多周期模式下**完全支持**画线下单功能：

1. 点击"**画线下单**"按钮启用画线模式
2. 在图表上画线创建挂单、止损、止盈线
3. 价格突破时自动触发下单
4. 功能与单周期模式完全一致

### 4.2 合约切换

1. 在"合约"输入框输入新合约代码（如 `MHI2512.HKFE`）
2. 按回车键或点击"切换"按钮
3. 系统会自动加载新合约的所有周期历史数据
4. 实时更新功能自动切换到新合约

### 4.3 时间导航

- **滚动条**: 拖动底部滚动条浏览历史数据
- **跳转到最新**: 点击"最新"按钮
- **跳转到指定时间**: 点击"跳转"按钮，输入日期时间

所有时间导航功能在多周期模式下都可正常使用。

### 4.4 实时更新

多周期模式下，所有周期的K线都会**自动实时更新**：
- 接收到tick数据后，系统自动聚合更新各周期K线
- 1分钟K线实时跳动
- 5分钟、1小时、4小时K线在各自周期结束时刷新

## 五、切换回单周期模式

### 5.1 操作方法

1. 点击"显示模式"下拉框
2. 选择"**单周期**"选项
3. 图表切换回传统的单周期K线显示

### 5.2 界面变化

- 多周期K线隐藏
- "多周期设置"按钮隐藏
- "周期选择"下拉框重新显示
- 恢复到传统单周期K线图表

### 5.3 数据保留

切换回单周期模式时：
- ✅ 历史数据保留（不需要重新加载）
- ✅ 画线交易状态保留
- ✅ 时间范围保留
- ✅ 合约信息保留

再次切换回多周期模式时，数据可以立即复用。

## 六、使用场景示例

### 场景1: 日内交易

```
显示模式: 多周期
合约: MHImain.HKFE

观察：
- 4小时K线：判断整体趋势方向
- 1小时K线：确认中期趋势和支撑/阻力位
- 5分钟K线：寻找入场时机
- 1分钟K线：精确入场点位

操作：
1. 在1小时支撑位附近
2. 等待5分钟K线确认反弹
3. 1分钟K线出现买入信号
4. 启用画线下单，在支撑位上方画挂单线
```

### 场景2: 趋势跟踪

```
显示模式: 多周期
设置: 隐藏1分钟K线，保留5m/1H/4H

观察：
- 4小时K线：主趋势
- 1小时K线：趋势延续确认
- 5分钟K线：回调入场点

操作：
1. 确认4小时上升趋势
2. 等待1小时回调到支撑
3. 5分钟K线出现反弹信号
4. 画止损线和止盈线
```

## 七、快捷键（可选扩展）

当前版本支持的快捷键：
- **ESC**: 退出画线模式
- **滚轮**: 缩放图表
- **拖拽**: 移动时间范围

*注：模式切换暂无快捷键，需要点击下拉框选择*

## 八、常见问题

### Q1: 切换到多周期模式后图表空白？
**A**: 请确保：
- 已加载历史数据（点击"查询历史"按钮）
- 合约代码正确
- 数据库中有该合约的数据

### Q2: 某个周期的K线没有显示？
**A**: 检查：
- 打开"多周期设置"，确认该周期已勾选
- 调整透明度，可能是因为透明度太高看不清
- 确认数据库中有该周期的数据

### Q3: 实时K线没有更新？
**A**: 确认：
- 交易网关已连接
- 已订阅该合约的行情
- 当前在交易时间段内

### Q4: 画线下单不起作用？
**A**: 检查：
- 是否点击了"画线下单"按钮启用
- 是否在正确的价格区域画线
- 检查日志窗口的错误信息

### Q5: 模式切换很慢？
**A**: 正常情况下切换应该 < 500ms
- 首次切换到多周期可能需要加载数据
- 后续切换会复用数据，速度很快
- 如果持续缓慢，检查数据量是否过大

## 九、性能提示

### 9.1 推荐配置

- **数据量**: 建议加载不超过5000根1分钟K线
- **内存**: 建议系统可用内存 > 4GB
- **显示器**: 建议分辨率 >= 1920x1080

### 9.2 优化建议

如果图表渲染较慢：
1. 减少显示的周期数量（隐藏部分周期）
2. 调整透明度为较低值（减少重叠渲染）
3. 减少加载的历史数据量
4. 关闭不需要的其他窗口
