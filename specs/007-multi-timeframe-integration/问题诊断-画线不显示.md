# 问题诊断：多周期模式下画线不显示

## 问题描述

- **症状**: 多周期模式下，画线下单的挂单线、止损线、止盈线都不显示
- **确认**: 单周期模式下画线功能正常
- **环境**: 多周期叠加模式

## 可能的原因

### 原因1: vt_symbol 参数错误

**问题**: `enable_drawing_order()` 传入的 vt_symbol 可能不正确

在 `vnpy/trader/ui/widget.py` 的 `_switch_to_multi_timeframe_mode()` 中：

```python
self.multi_timeframe_widget.enable_drawing_order(
    main_engine=self.main_engine,
    vt_symbol=self.current_vt_symbol,  # ← 可能是 "MHImain.HKFE"
    on_drawing_click=self._on_drawing_click
)
```

**问题**: 如果传入的是完整的 vt_symbol（如 `"MHImain.HKFE"`），但内部使用的是 symbol（如 `"MHImain"`），会导致不匹配。

### 原因2: ChartWidget 的 vt_symbol 未设置

在 `multi_timeframe_widget.py` 的 `enable_drawing_order()` 中：

```python
def enable_drawing_order(
    self,
    main_engine: object,
    vt_symbol: str,
    on_drawing_click: callable | None = None
) -> None:
    if not self._chart:
        return
    
    # 设置 main_engine 和 vt_symbol
    self._chart.set_main_engine(main_engine)
    self._chart.set_vt_symbol(vt_symbol)  # ← 这里设置的 vt_symbol 可能不对
```

**问题**: 如果 `vt_symbol` 参数格式不对，`ChartWidget` 内部的价格线管理器就无法正确关联价格线。

### 原因3: DrawingOrderController 未正确初始化

**问题**: `DrawingOrderController` 可能没有正确设置 `main_engine` 和 `vt_symbol`。

### 原因4: 价格线被添加到错误的图表

**问题**: 价格线可能被添加到了 `ChartWindow.chart` 而不是 `MultiTimeframeWidget._chart`。

## 可能的解决方案

### 方案1: 确保传入完整的 vt_symbol

在 `vnpy/trader/ui/widget.py` 中：

```python
# 在 _switch_to_multi_timeframe_mode() 中
self.multi_timeframe_widget.enable_drawing_order(
    main_engine=self.main_engine,
    vt_symbol=self.current_vt_symbol,  # "MHImain.HKFE" - 完整的vt_symbol
    on_drawing_click=self._on_drawing_click
)
```

### 方案2: 在 toggle_drawing_mode 中重新设置

在启用画线模式时，重新设置 vt_symbol：

```python
def toggle_drawing_mode(self) -> None:
    """切换画线下单模式"""
    is_enabled = self.drawing_mode_button.isChecked()
    
    if self.display_mode == "multi":
        # 多周期模式
        if self.multi_timeframe_widget and self.multi_timeframe_widget._chart:
            chart = self.multi_timeframe_widget._chart
            
            # 重新设置 vt_symbol（确保正确）
            chart.set_vt_symbol(self.current_vt_symbol)
            
            controller = chart.get_drawing_order_controller()
            if controller:
                if is_enabled:
                    controller.enable()
                else:
                    controller.disable()
```

### 方案3: 检查 PriceLineManager

确保 `PriceLineManager` 正确初始化并关联到图表：

```python
# 在 ChartWidget 初始化时
if not hasattr(self, '_price_line_manager'):
    from vnpy.chart.price_line_manager import PriceLineManager
    self._price_line_manager = PriceLineManager(self)
```
