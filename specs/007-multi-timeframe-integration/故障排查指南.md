# 多周期模式故障排查指南

## 问题1: 切换多周期显示无数据

### 症状

```
切换到多周期模式后显示空白
日志显示: "未找到1分钟K线数据"
单周期模式有数据，多周期模式无数据
```

### 原因分析

1. **数据未同步**: 切换到多周期模式时，`sync_data_to_multi_timeframe()` 可能未正确执行
2. **数据源问题**: `history_data` 为空或不完整
3. **时间范围问题**: 起始和结束时间设置不正确
4. **数据库查询失败**: MultiTimeframeWidget 从数据库加载数据失败

### 🔍 诊断步骤

#### 步骤1: 检查单周期模式是否有数据

1. 切换回单周期模式
2. 点击"查询历史"按钮
3. 确认K线图表显示数据
4. 记录合约代码和时间范围

#### 步骤2: 检查日志输出

查看控制台或日志文件，寻找以下关键信息：

**正常日志**:
```

[ChartWindow] 同步数据到多周期Widget，数据量: 1000
[MultiTimeframeWidget] 加载历史数据: MHImain.HKFE, 2025-11-27 to 2025-12-04
[MultiTimeframeWidget] 1分钟K线数据: 1000条
```

**异常日志**:
```
未找到1分钟K线数据  ← 数据加载失败
[MultiTimeframeWidget] history_data为空  ← ChartWindow 没有数据
[MultiTimeframeWidget] 数据库查询失败  ← 数据库连接或查询问题
```

### 🔧 解决方案

#### 解决方案1: 先加载数据，再切换模式

**步骤**:
1. 保持在单周期模式
2. 点击"查询历史"按钮，加载数据
3. 确认K线图表显示数据
4. 再切换到多周期模式

**原理**: 确保 `history_data` 有数据后再切换

#### 解决方案2: 在多周期模式下重新加载数据

**步骤**:
1. 切换到多周期模式
2. 在"数据源"选择"数据库"
3. 设置起始时间（如最近一周）
4. 点击"加载"按钮
5. 观察图表是否显示数据

```python
def sync_data_to_multi_timeframe(self) -> None:
    """同步单周期数据到多周期Widget"""
    if not self.multi_timeframe_widget:
        self.main_engine.write_log(
            "[ChartWindow] multi_timeframe_widget 未初始化",
            "ChartWindow"
        )
        return
    
    if not self.history_loaded or not self.history_data:
        self.main_engine.write_log(
            f"[ChartWindow] 无数据可同步 - history_loaded:{self.history_loaded}, "
            f"data_count:{len(self.history_data) if self.history_data else 0}",
            "ChartWindow"
        )
        # 尝试从数据库加载数据
        if self.current_vt_symbol:
            self.main_engine.write_log(
                f"[ChartWindow] 尝试从数据库加载数据: {self.current_vt_symbol}",
                "ChartWindow"
            )
            # 这里可以添加从数据库加载的逻辑
        return
    
    self.main_engine.write_log(
        f"[ChartWindow] 开始同步数据到多周期Widget - "
        f"合约:{self.current_vt_symbol}, 数据量:{len(self.history_data)}",
        "ChartWindow"
    )
    
    # 获取时间范围
    if self.history_data:
        start = self.history_data[0].datetime
        end = self.history_data[-1].datetime
        
        self.main_engine.write_log(
            f"[ChartWindow] 数据时间范围: {start} ~ {end}",
            "ChartWindow"
        )
        
        # 调用 MultiTimeframeWidget 的切换合约方法
        self.multi_timeframe_widget.switch_symbol(
            vt_symbol=self.current_vt_symbol,
            start=start,
            end=end
        )
```

## 问题2: 切换模式后程序卡顿

### 症状
- 切换到多周期模式时程序无响应
- 鼠标变成加载状态
- 需要等待较长时间

### 原因
- 数据量过大（超过5000条1分钟K线）
- 首次加载需要聚合计算
- 数据库查询缓慢

### 解决方案

1. **减少数据量**:
   - 调整起始时间，只加载最近几天的数据
   - 建议：最近3-7天

2. **使用进度提示**:
   - 显示"正在加载多周期数据..."提示

3. **异步加载**:
   - 将数据加载放到后台线程

## 问题3: 多周期K线显示不全

### 症状
- 只显示1分钟K线，其他周期不显示
- 或者某些周期的K线缺失

### 解决方案

1. **打开多周期设置**:
   - 点击"多周期设置"按钮
   - 检查各周期是否勾选显示
   - 调整透明度（建议80-95%）

2. **检查数据**:
   - 确认数据库中有各周期的数据
   - 或者确认聚合计算正常工作

## 问题4: 实时更新不工作

### 症状
- K线不跳动
- 收到tick但K线不更新

### 解决方案

1. **检查网关连接**:
   - 确认交易网关已连接
   - 确认已订阅该合约的行情

2. **检查实时更新是否启用**:
   - 日志应显示"实时更新功能已启用"
   - 确认 `enable_realtime()` 被调用

3. **检查tick路由**:
   - 在 `process_tick_event()` 中确认tick被正确路由到 `MultiTimeframeWidget.update_tick()`
