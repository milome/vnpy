# 功能恢复：阳线填充

## 修改内容

已恢复POC版本的阳线填充功能，使多周期K线显示更美观和统一。

## 修改的文件

### 1. `vnpy/chart/cross_index_candle_item.py`

#### 修改点1: 初始化方法

**之前**:
- 阳线：空心（`QtCore.Qt.NoBrush`）
- 阴线：有填充

**现在**:
- 阳线：有填充（与阴线共享透明度）
- 阴线：有填充
- 使用统一的 `_fill_opacity` 属性

#### 修改点2: 新增方法

添加了 `_update_bullish_brush()` 方法，用于更新阳线填充画刷。

#### 修改点3: 更新方法

修改了 `set_bearish_fill_opacity()` 方法：
- **功能扩展**: 现在同时更新阳线和阴线的填充透明度
- **保持兼容**: 方法名保持不变，确保现有代码无需修改

#### 修改点4: 绘制逻辑

修改了 `_draw_bar_picture()` 方法：

**之前**:
```python
if close_price < open_price:
    painter.setBrush(self._bearish_brush)  # 阴线填充
else:
    painter.setBrush(QtCore.Qt.BrushStyle.NoBrush)  # 阳线空心
```

**现在**:
```python
if close_price < open_price:
    painter.setBrush(self._bearish_brush)  # 阴线填充
else:
    painter.setBrush(self._bullish_brush)  # 阳线也填充
```

## 效果对比

### 修改前

```
阳线（红色）: 只有边框，中间空心
阴线（青色）: 有边框和填充（可调透明度）
```

视觉效果：不够统一，阳线和阴线差异较大

### 修改后

```
阳线（红色）: 边框 + 填充（可调透明度）
阴线（青色）: 边框 + 填充（可调透明度）
```

视觉效果：统一美观，两者使用相同的透明度设置

## 用户体验改进

### 1. 视觉统一性
- 阳线和阴线的视觉风格一致
- 更容易区分不同周期的K线

### 2. 设置简化
- 一个透明度滑块同时控制阳线和阴线
- 用户无需分别设置两个透明度

### 3. 界面清晰度
- 通过调整透明度，可以让多周期K线叠加时更清晰
- 避免K线之间相互遮挡

- 参数和返回值保持不变
