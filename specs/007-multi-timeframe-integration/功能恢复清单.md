- 添加 `_bullish_color` 和 `_bearish_color` 属性
- 添加 `_update_bullish_brush()` 方法
- 修改初始化逻辑，阳线也创建填充画刷

### 2. 阳线填充画刷 ✅

**新增方法**: `_update_bullish_brush()`

```python
def _update_bullish_brush(self) -> None:
    """根据当前的不透明度设置更新阳线填充画刷。"""
    bullish_brush_color = QtGui.QColor(self._bullish_color)
    bullish_brush_color.setAlphaF(self._fill_opacity)
    self._bullish_brush = pg.mkBrush(color=bullish_brush_color)
```

### 3. 阴线填充画刷更新 ✅

**修改方法**: `_update_bearish_brush()`

- 使用 `_fill_opacity` 替代 `_bearish_fill_opacity`
- 确保与阳线使用相同的透明度

### 4. 透明度设置方法 ✅

**修改方法**: `set_bearish_fill_opacity()`

```python
def set_bearish_fill_opacity(self, opacity: float) -> None:
    """设置填充透明度（阳线阴线共享）。"""
    self._fill_opacity = max(0.0, min(1.0, opacity))
    self._update_bullish_brush()  # 同时更新阳线
    self._update_bearish_brush()  # 和阴线
    # ...
```

**注意**: 方法名保持不变，确保向后兼容

### 5. 绘制逻辑修改 ✅

**修改方法**: `_draw_bar_picture()`

**之前**:
```python
if close_price < open_price:
    painter.setBrush(self._bearish_brush)  # 只有阴线填充
# 阳线不绘制填充矩形
```

**现在**:
```python
# 阳线阴线都绘制填充矩形
if close_price < open_price:
    painter.setBrush(self._bearish_brush)  # 阴线填充
else:
    painter.setBrush(self._bullish_brush)  # 阳线也填充
painter.drawRect(fill_rect)
```

## 📊 透明度共享机制

### 工作原理

1. **用户操作**: 在设置对话框调整透明度滑块
2. **调用方法**: `set_bearish_fill_opacity(opacity)`
3. **内部处理**: 
   - 更新 `_fill_opacity` 值
   - 调用 `_update_bullish_brush()` 更新阳线画刷
   - 调用 `_update_bearish_brush()` 更新阴线画刷
4. **清除缓存**: 清空已缓存的bar图片
5. **重新绘制**: 下次绘制时使用新的透明度

### 优势

- ✅ **简化用户操作**: 一个滑块控制所有
- ✅ **保持一致性**: 阳线阴线透明度始终一致
- ✅ **向后兼容**: API 接口保持不变
