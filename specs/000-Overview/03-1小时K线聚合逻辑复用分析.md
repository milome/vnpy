# 1小时K线聚合逻辑复用分析

## 问题

1小时K线数据由多个模块聚合而成：
- **DataManager** (`vnpy_datamanager/vnpy_datamanager/engine.py`): `aggregate_hour_bars()` 方法
- **ChartWindow** (`vnpy/trader/ui/widget.py`): 数据补齐时调用DataManager的 `aggregate_hour_bars()`
- **示例代码** (`examples/candle_chart/one_hour_aggregator.py`): `aggregate_to_1hour()` 函数

这些代码存在重复逻辑，需要提取共同逻辑以便复用。

## 代码位置分析

### 1. DataManager (`vnpy_datamanager/vnpy_datamanager/engine.py`)

**方法**: `aggregate_hour_bars()` (第486-663行)

**功能**:
- 从数据库加载1分钟K线数据
- 使用 `get_hkfe_hour_period_start()` 分组
- 计算OHLCV并创建1小时K线
- 保存到数据库
- 返回合成的K线数量

**特点**:
- 包含时区处理（`DB_TZ`）
- 包含进度日志（每10000条记录一次）
- 包含数据库保存逻辑
- 包含数据范围检查（已有数据检查）

### 2. 示例代码 (`examples/candle_chart/one_hour_aggregator.py`)

**函数**: `aggregate_to_1hour()` (第32-93行)

**功能**:
- 从1分钟K线列表聚合
- 使用 `get_hkfe_hour_period_start()` 分组
- 计算OHLCV并创建1小时K线
- 返回列表（不保存到数据库）

**特点**:
- 简单直接，无时区处理
- 无进度日志
- 无数据库保存逻辑

### 3. ChartWindow (`vnpy/trader/ui/widget.py`)

**位置**: 第4690-4738行（数据补齐时）

**功能**:
- 调用DataManager的 `aggregate_hour_bars()` 方法
- 如果DataManager不可用，降级到通用合成方法 `_synthesize_bars_from_minute()`

**特点**:
- 依赖DataManager的聚合逻辑
- 有降级处理机制

## 共同逻辑提取

### 核心聚合逻辑

所有实现都包含以下共同逻辑：

1. **周期分组**:
   ```python
   period_groups: dict[datetime, List[BarData]] = {}
   for bar in one_minute_bars:
       period_start = get_hkfe_hour_period_start(bar.datetime)
       if period_start is None:
           continue
       if period_start not in period_groups:
           period_groups[period_start] = []
       period_groups[period_start].append(bar)
   ```

2. **OHLCV计算**:
   ```python
   bars.sort(key=lambda x: x.datetime)  # 确保按时间排序
   open_price = bars[0].open_price       # 第一根的开盘价
   close_price = bars[-1].close_price   # 最后一根的收盘价
   high_price = max(bar.high_price for bar in bars)
   low_price = min(bar.low_price for bar in bars)
   volume = sum(bar.volume for bar in bars)
   turnover = sum(bar.turnover for bar in bars)  # DataManager有，示例代码没有
   open_interest = bars[-1].open_interest        # DataManager有，示例代码没有
   ```

3. **创建BarData对象**:
   ```python
   hour_bar = BarData(
       symbol=symbol,
       exchange=exchange,
       datetime=period_start,
       interval=Interval.HOUR,
       open_price=open_price,
       high_price=high_price,
       low_price=low_price,
       close_price=close_price,
       volume=volume,
       turnover=turnover,
       open_interest=open_interest,
       gateway_name=gateway_name,
   )
   ```

### 差异点

1. **时区处理**: DataManager有时区处理，示例代码没有
2. **进度日志**: DataManager有进度日志，示例代码没有
3. **数据库保存**: DataManager保存到数据库，示例代码只返回列表
4. **数据范围检查**: DataManager检查已有数据范围，示例代码没有
