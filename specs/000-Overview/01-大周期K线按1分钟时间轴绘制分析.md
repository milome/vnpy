# 大周期K线按1分钟时间轴绘制分析

## 问题描述

在多周期K线叠加显示中，需要将不同周期的K线（1分钟、5分钟、1小时、4小时等）统一绘制在同一个图表上。核心挑战是：

**如何将大周期K线（5分钟、1小时、4小时等）映射到1分钟时间轴上，实现历史和实时K线的正确绘制？**

## 当前实现分析

### 1. 现有架构

#### BarManager 数据结构
```python
class BarManager:
    _bars: dict[datetime, BarData]  # datetime -> BarData 映射
    _datetime_index_map: dict[datetime, int]  # datetime -> 索引
    _index_datetime_map: dict[int, datetime]  # 索引 -> datetime
```

**特点**：
- 每个K线对应一个索引位置（0, 1, 2, ...）
- 索引是连续的，每个K线占据一个索引位置
- 当前设计假设所有K线都是同一周期

#### CandleItem 绘制逻辑
```python
def _draw_bar_picture(self, ix: int, bar: BarData):
    # ix 是索引位置，bar 是K线数据
    # 在 ix 位置绘制K线
```

**特点**：
- 使用索引（ix）作为X轴位置
- 每个K线在X轴上占据一个单位宽度
- 无法直接处理跨多个索引位置的K线

### 2. 前端实现参考（multi-timeframe-webapp）

在 `EChartsTradingChart.tsx` 中的实现方式：

```typescript
// 1. 使用1分钟数据作为X轴基准
let baseData = filteredOneMinData

// 2. 创建时间戳到索引的映射
const timestampToIndex = new Map<number, number>()

})

// 3. 将4小时K线映射到1分钟时间轴
// 通过查找4小时K线的起始和结束时间对应的1分钟索引
```

**关键思路**：
- 以1分钟数据作为时间轴基准
- 大周期K线通过时间戳映射到对应的1分钟索引位置
- 大周期K线可以跨越多个1分钟索引位置

## 解决方案设计

### 方案1：时间轴映射法（推荐）

#### 核心思想
1. **统一时间轴**：以1分钟K线数据作为X轴基准，建立 `datetime -> index` 的映射
2. **大周期K线映射**：将大周期K线的起始和结束时间映射到对应的1分钟索引位置
3. **绘制位置计算**：大周期K线在起始索引位置绘制，宽度为 `结束索引 - 起始索引`

#### 数据结构设计

```python
class MultiTimeframeBarManager:
    """多周期K线管理器"""
    
    def __init__(self):
        # 1分钟K线数据（作为时间轴基准）
        self._base_bars: dict[datetime, BarData] = {}
        self._datetime_index_map: dict[datetime, int] = {}
        self._index_datetime_map: dict[int, datetime] = {}
        
        # 大周期K线数据（按周期分组）
        self._timeframe_bars: dict[str, dict[datetime, BarData]] = {
            "5m": {},
            "1h": {},
            "4h": {},
            "1d": {}
        }
        
        # 大周期K线的时间范围映射
        # 格式：timeframe -> {bar_datetime: (start_index, end_index)}
        self._timeframe_range_map: dict[str, dict[datetime, tuple[int, int]]] = {
            "5m": {},
            "1h": {},
            "4h": {},
            "1d": {}
        }
```

#### 映射算法

```python
def map_timeframe_to_base_index(
    self, 
    timeframe: str, 
    bar_datetime: datetime
) -> tuple[int, int] | None:
    """
    将大周期K线映射到1分钟时间轴索引范围
    
    Args:
        timeframe: 周期标识（"5m", "1h", "4h", "1d"）
        bar_datetime: 大周期K线的开始时间
        
    Returns:
        (start_index, end_index) 或 None（如果无法映射）
    """
    # 1. 计算大周期K线的结束时间
    end_datetime = self._calculate_period_end(timeframe, bar_datetime)
    
    # 2. 查找起始和结束时间对应的1分钟索引
    start_index = self._datetime_index_map.get(bar_datetime)
    end_index = self._datetime_index_map.get(end_datetime)
    
    if start_index is None or end_index is None:
        return None
    
    return (start_index, end_index)
```

#### 绘制逻辑

```python
class MultiTimeframeCandleItem(ChartItem):
    """多周期K线绘制项"""
    
    def _draw_bar_picture(self, ix: int, bar: BarData, timeframe: str):
        """
        绘制大周期K线
        
        Args:
            ix: 起始索引位置
            bar: K线数据
            timeframe: 周期标识

        width = end_ix - start_ix + 1

        # 注意：需要调整绘制逻辑，使K线跨越多个索引位置
        self._draw_candlestick_at_range(start_ix, end_ix, bar)
```

### 方案2：虚拟索引法

#### 核心思想
为每个周期创建独立的索引空间，但在绘制时统一映射到1分钟时间轴。

**优点**：实现简单，不需要修改现有绘制逻辑
**缺点**：需要额外的映射层，可能影响性能

### 方案3：分层绘制法

#### 核心思想
不同周期使用不同的图层（PlotItem），但共享同一个X轴（时间轴）。

**优点**：各周期独立管理，互不干扰
**缺点**：需要多个PlotItem，可能影响性能

## 推荐方案：时间轴映射法

### 实现步骤

#### 步骤1：建立1分钟时间轴基准

```python
def set_base_timeline(self, one_minute_bars: list[BarData]):
    """
    设置1分钟K线作为时间轴基准
    
    Args:
        one_minute_bars: 1分钟K线数据列表（已排序）
    """
    # 清空现有数据
    self._base_bars.clear()
    self._datetime_index_map.clear()
    self._index_datetime_map.clear()
    
    # 建立映射
    for index, bar in enumerate(one_minute_bars):
        dt = bar.datetime
        self._base_bars[dt] = bar
        self._datetime_index_map[dt] = index
        self._index_datetime_map[index] = dt
```

#### 步骤2：添加大周期K线并建立映射

```python
def add_timeframe_bars(
    self, 
    timeframe: str, 
    bars: list[BarData]
):
    """
    添加大周期K线数据并建立时间轴映射
    
    Args:
        timeframe: 周期标识（"5m", "1h", "4h", "1d"）
        bars: 大周期K线数据列表（已排序）
    """
    if timeframe not in self._timeframe_bars:
        self._timeframe_bars[timeframe] = {}
        self._timeframe_range_map[timeframe] = {}
    
    for bar in bars:
        dt = bar.datetime
        
        # 存储K线数据
        self._timeframe_bars[timeframe][dt] = bar
        
        # 计算时间范围映射
        start_ix, end_ix = self._map_to_base_index(timeframe, dt)
        if start_ix is not None and end_ix is not None:
            self._timeframe_range_map[timeframe][dt] = (start_ix, end_ix)
```

#### 步骤3：计算周期结束时间

```python
def _calculate_period_end(
    self, 
    timeframe: str, 
    start_datetime: datetime
) -> datetime:
    """
    计算大周期K线的结束时间
    
    Args:
        timeframe: 周期标识
        start_datetime: 周期开始时间
        
    Returns:
        周期结束时间（不包含，即下一个周期的开始时间）
    """
    from datetime import timedelta
    from vnpy.trader.constant import Interval
    
    # 根据周期计算时间增量
    if timeframe == "5m":
        delta = timedelta(minutes=5)
    elif timeframe == "1h":
        delta = timedelta(hours=1)
    elif timeframe == "4h":
        # 4小时周期需要特殊处理（HKFE交易时段）
        delta = self._calculate_4h_period_end(start_datetime)
    elif timeframe == "1d":
        delta = timedelta(days=1)
    else:
        raise ValueError(f"Unsupported timeframe: {timeframe}")
    
    return start_datetime + delta
```

#### 步骤4：实时K线更新

```python
def update_realtime_bar(
    self, 
    timeframe: str, 
    bar: BarData
):
    """
    更新实时大周期K线
    
    Args:
        timeframe: 周期标识
        bar: 实时K线数据（可能未完成）
    """
    dt = bar.datetime
    
    # 更新K线数据
    if timeframe not in self._timeframe_bars:
        self._timeframe_bars[timeframe] = {}
        self._timeframe_range_map[timeframe] = {}
    
    self._timeframe_bars[timeframe][dt] = bar
    
    # 重新计算时间范围映射（因为可能新增了1分钟K线）
    start_ix, end_ix = self._map_to_base_index(timeframe, dt)
    if start_ix is not None:
        # 对于实时K线，end_ix 可能是当前最新的1分钟索引
        current_max_ix = len(self._base_bars) - 1
        end_ix = end_ix if end_ix is not None else current_max_ix
        self._timeframe_range_map[timeframe][dt] = (start_ix, end_ix)
```

### 绘制实现

#### 修改 CandleItem 支持跨索引绘制

```python
class MultiTimeframeCandleItem(ChartItem):
    """支持多周期K线绘制的CandleItem"""
    
    def _draw_bar_picture(
        self, 
        ix: int, 
        bar: BarData, 
        timeframe: str = "1m"
    ) -> QtGui.QPicture:
        """
        绘制K线（支持跨索引位置）
        
        Args:
            ix: 起始索引位置
            bar: K线数据
            timeframe: 周期标识
        """
        # 1. 获取时间范围
        if timeframe == "1m":
            # 1分钟K线：占据一个索引位置
            start_ix = ix
            end_ix = ix
        else:
            # 大周期K线：获取时间范围
            range_map = self._manager.get_timeframe_range_map(timeframe)
            start_ix, end_ix = range_map.get(bar.datetime, (ix, ix))
        
        # 2. 计算绘制位置和宽度
        # 在起始索引位置绘制，但宽度跨越到结束索引
        center_ix = (start_ix + end_ix) / 2.0
        width = end_ix - start_ix + 1
        
        # 3. 绘制K线
        candle_picture = QtGui.QPicture()
        painter = QtGui.QPainter(candle_picture)
        
        # 设置颜色
        if bar.close_price >= bar.open_price:
            painter.setPen(self._up_pen)
            painter.setBrush(self._black_brush)
        else:
            painter.setPen(self._down_pen)
            painter.setBrush(self._down_brush)
        
        # 绘制影线（在中心位置）
        if bar.high_price > bar.low_price:
            painter.drawLine(
                QtCore.QPointF(center_ix, bar.high_price),
                QtCore.QPointF(center_ix, bar.low_price)
            )
        
        # 绘制实体（跨越时间范围）
        if bar.open_price == bar.close_price:
            # 十字星：绘制水平线
            painter.drawLine(
                QtCore.QPointF(start_ix, bar.open_price),
                QtCore.QPointF(end_ix, bar.open_price)
            )
        else:
            # 实体：绘制矩形，宽度为时间范围
            rect = QtCore.QRectF(
                start_ix - BAR_WIDTH,
                min(bar.open_price, bar.close_price),
                (end_ix - start_ix + 1) + BAR_WIDTH * 2,
                abs(bar.close_price - bar.open_price)
            )
            painter.drawRect(rect)
        
        painter.end()
        return candle_picture
```

## 实时K线更新策略

### 历史K线加载
1. 先加载1分钟K线数据，建立时间轴基准
2. 从1分钟数据合成大周期K线
3. 建立大周期K线到1分钟时间轴的映射

### 实时K线更新
1. **1分钟K线更新**：
   - 直接添加到 `_base_bars`
   - 更新索引映射
   - 触发大周期K线重新计算

2. **大周期K线更新**：
   - 检查当前tick是否属于某个大周期
   - 更新对应大周期K线的 high/low/close
   - 更新时间范围映射（end_ix 可能变化）

3. **周期完成处理**：
   - 当大周期结束时，标记K线为已完成
   - 不再更新该K线
   - 准备下一个周期的K线

## 关键挑战和解决方案

### 挑战1：休市时间处理
**问题**：4小时K线可能跨越休市时间（如01:15-03:00 + 09:15-11:29）

**解决方案**：
- 在计算时间范围映射时，跳过休市时间段的1分钟索引
- 使用实际交易时间段的1分钟K线来建立映射

### 挑战2：性能优化
**问题**：大量K线数据可能导致绘制性能下降

**解决方案**：
- 只绘制可见范围内的K线（已实现）
- 使用缓存机制，避免重复计算时间范围映射
- 对于历史数据，预先计算并存储映射关系

### 挑战3：实时更新同步
**问题**：多个周期需要同时更新，如何保证一致性

**解决方案**：
- 以1分钟K线更新为驱动
- 大周期K线更新作为1分钟K线更新的副作用
- 使用事件机制通知各周期更新
