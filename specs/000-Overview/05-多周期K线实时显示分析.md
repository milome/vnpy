# 多周期K线实时显示分析

## 概述

本文档分析如何在 `MultiTimeframeWidget` 中实现多周期K线的实时显示功能。

## 现有架构分析

### 1. ChartWidget 实时更新机制

`ChartWidget` 提供了两个主要的更新方法：

```python
# 更新历史K线列表
def update_history(self, history: list[BarData]) -> None:
    self._manager.update_history(history)
    for item in self._items.values():
        item.update_history(history)
    self._update_plot_limits()
    self.move_to_right()

# 更新单根K线（实时更新）
def update_bar(self, bar: BarData) -> None:
    self._manager.update_bar(bar)
    for item in self._items.values():
        item.update_bar(bar)
    self._update_plot_limits()
    # 自动跟随到最新位置
    if self._right_ix <= data_count and self._right_ix >= (data_count - self._bar_count / 2):
        self.move_to_right()
```

**关键点**：
- `update_bar` 用于实时更新单根K线
- 会自动更新所有注册的 `ChartItem`
- 支持视图自动跟随到最新位置

### 2. BarManager 更新机制

```python
class BarManager:
    def update_bar(self, bar: BarData) -> None:
        """更新单根K线"""
        dt: datetime = bar.datetime
        
        # 如果K线不存在，添加新索引
        if dt not in self._datetime_index_map:
            ix: int = len(self._bars)
            self._datetime_index_map[dt] = ix
            self._index_datetime_map[ix] = dt
        
        self._bars[dt] = bar
        self._clear_cache()  # 清除价格范围缓存
```

**关键点**：
- 支持新增K线和更新已有K线
- 自动维护 datetime <-> index 映射
- 更新后清除缓存，触发重新计算

### 3. ChartItem 更新机制

```python
class ChartItem:
    def update_bar(self, bar: BarData) -> None:
        """更新单根K线"""
        ix: int | None = self._manager.get_index(bar.datetime)
        if ix is None:
            return
        
        # 释放旧的QPicture对象，防止资源泄漏
        old_picture = self._bar_picutures.get(ix)
        if old_picture is not None:
            del old_picture
        
        self._bar_picutures[ix] = None  # 标记需要重新绘制
        self.update()  # 触发重绘
```

**关键点**：
- 通过 `manager.get_index()` 获取K线索引
- 清除旧的绘制缓存，触发重新绘制
- 使用 `update()` 通知场景更新

### 4. BarGenerator 多周期合成机制

`HKFEBarGenerator` 支持从1分钟K线合成大周期K线：

```python
class HKFEBarGenerator(BarGenerator):
    def update_bar(self, bar: BarData) -> None:
        """从1分钟K线合成大周期K线"""
        if self.interval == Interval.MINUTE_5:
            self._update_bar_hkfe_5minute(bar)
        elif self.interval == Interval.HOUR:
            self._update_bar_hkfe_hour(bar)
        elif self.interval == Interval.HOUR_4:
            self._update_bar_hkfe_4hour(bar)
```

**关键点**：
- 接收1分钟K线作为输入
- 根据周期类型调用相应的合成方法
- 使用 `on_window_bar` 回调通知合成完成的K线

## 多周期实时更新方案

### 方案1：基于BarGenerator的级联更新（推荐）

**架构**：
```
Tick数据 
  → BarGenerator(1m) → 1分钟K线
    → BarGenerator(5m) → 5分钟K线
    → BarGenerator(1H) → 1小时K线
    → BarGenerator(4H) → 4小时K线
```

**实现步骤**：

1. **创建多级BarGenerator**：
```python
class MultiTimeframeWidget:
    def __init__(self, ...):
        # ... 现有初始化代码 ...
        
        # 创建多级BarGenerator
        self._bg_1m = BarGenerator(
            on_bar=self._on_1m_bar,
            interval=Interval.MINUTE
        )
        
        self._bg_5m = HKFEBarGenerator(
            on_bar=self._on_5m_bar,
            interval=Interval.MINUTE_5,
            exchange=self._exchange,
            symbol=self._vt_symbol
        )
        
        self._bg_1h = HKFEBarGenerator(
            on_bar=self._on_1h_bar,
            interval=Interval.HOUR,
            exchange=self._exchange,
            symbol=self._vt_symbol
        )
        
        self._bg_4h = HKFEBarGenerator(
            on_bar=self._on_4h_bar,
            interval=Interval.HOUR_4,
            exchange=self._exchange,
            symbol=self._vt_symbol
        )
```

2. **实现回调函数**：
```python
def _on_1m_bar(self, bar: BarData) -> None:
    """1分钟K线更新回调"""
    # 更新主图（1分钟K线）
    self._chart.update_bar(bar)
    
    # 传递给5分钟、1小时、4小时BarGenerator
    self._bg_5m.update_bar(bar)
    self._bg_1h.update_bar(bar)
    self._bg_4h.update_bar(bar)

def _on_5m_bar(self, bar: BarData) -> None:
    """5分钟K线更新回调"""
    if self._manager_5m:
        self._manager_5m.update_bar(bar)
        if self._item_5m:
            self._item_5m.update_bar(bar)

def _on_1h_bar(self, bar: BarData) -> None:
    """1小时K线更新回调"""
    if self._manager_1h:
        self._manager_1h.update_bar(bar)
        if self._item_1h:
            self._item_1h.update_bar(bar)

def _on_4h_bar(self, bar: BarData) -> None:
    """4小时K线更新回调"""
    if self._manager_4h:
        self._manager_4h.update_bar(bar)
        if self._item_4h:
            self._item_4h.update_bar(bar)
```

3. **接收Tick数据**：
```python
def update_tick(self, tick: TickData) -> None:
    """接收Tick数据并更新所有周期"""
    # 传递给1分钟BarGenerator
    self._bg_1m.update_tick(tick)
```

**优点**：
- 利用现有的BarGenerator机制，代码简洁
- 自动处理周期边界判断
- 支持HKFE精确时间边界
- 级联更新，逻辑清晰

**缺点**：
- 需要维护多个BarGenerator实例
- 内存占用略高

### 方案2：手动聚合更新

**架构**：
```
Tick数据 → 手动聚合 → 直接更新各周期BarManager
```

**实现步骤**：

1. **手动判断周期边界**：
```python
def update_tick(self, tick: TickData) -> None:
    """接收Tick数据并手动更新所有周期"""
    # 1. 更新1分钟K线（使用BarGenerator）
    self._bg_1m.update_tick(tick)
    
    # 2. 获取当前1分钟K线
    current_1m_bar = self._bg_1m.bar
    if not current_1m_bar:
        return
    
    # 3. 手动判断并更新各周期
    self._update_5m_bar(current_1m_bar)
    self._update_1h_bar(current_1m_bar)
    self._update_4h_bar(current_1m_bar)

def _update_5m_bar(self, bar_1m: BarData) -> None:
    """手动更新5分钟K线"""
    period_start = get_period_start(bar_1m.datetime, Interval.MINUTE_5, self._exchange)
    if not period_start:
        return
    
    # 获取或创建5分钟K线
    if period_start not in self._manager_5m._bars:
        # 创建新K线
        bar_5m = BarData(...)
        self._manager_5m.update_bar(bar_5m)
    else:
        # 更新现有K线
        bar_5m = self._manager_5m._bars[period_start]
        bar_5m.high_price = max(bar_5m.high_price, bar_1m.high_price)
        bar_5m.low_price = min(bar_5m.low_price, bar_1m.low_price)
        bar_5m.close_price = bar_1m.close_price
        bar_5m.volume += bar_1m.volume
        self._manager_5m.update_bar(bar_5m)
    
    # 更新绘制项
    if self._item_5m:
        self._item_5m.update_bar(bar_5m)
```

**优点**：
- 完全控制更新逻辑
- 可以自定义聚合规则

**缺点**：
- 代码复杂，需要手动处理所有边界情况
- 容易出错，需要维护大量逻辑
- 与BarGenerator重复实现

## 推荐方案：方案1（基于BarGenerator）

### 实现细节

#### 1. 扩展MultiTimeframeWidget

```python
class MultiTimeframeWidget(QtWidgets.QWidget):
    def __init__(self, ...):
        # ... 现有初始化代码 ...
        
        # BarGenerator实例（用于实时更新）
        self._bg_1m: Optional[BarGenerator] = None
        self._bg_5m: Optional[HKFEBarGenerator] = None
        self._bg_1h: Optional[HKFEBarGenerator] = None
        self._bg_4h: Optional[HKFEBarGenerator] = None
        
        # 是否启用实时更新
        self._realtime_enabled: bool = False

    def enable_realtime(self) -> None:
        """启用实时更新功能"""
        if self._realtime_enabled:
            return
        
        from vnpy.trader.utility import BarGenerator
        from vnpy.trader.hkfe_bar_generator import HKFEBarGenerator
        
        # 创建1分钟BarGenerator
        self._bg_1m = BarGenerator(
            on_bar=self._on_1m_bar,
            interval=Interval.MINUTE
        )
        
        # 创建5分钟BarGenerator
        if self._manager_5m:
            self._bg_5m = HKFEBarGenerator(
                on_bar=self._on_5m_bar,
                interval=Interval.MINUTE_5,
                exchange=self._exchange,
                symbol=self._vt_symbol
            )
        
        # 创建1小时BarGenerator
        if self._manager_1h:
            self._bg_1h = HKFEBarGenerator(
                on_bar=self._on_1h_bar,
                interval=Interval.HOUR,
                exchange=self._exchange,
                symbol=self._vt_symbol
            )
        
        # 创建4小时BarGenerator
        if self._manager_4h:
            self._bg_4h = HKFEBarGenerator(
                on_bar=self._on_4h_bar,
                interval=Interval.HOUR_4,
                exchange=self._exchange,
                symbol=self._vt_symbol
            )
        
        self._realtime_enabled = True

    def update_tick(self, tick: TickData) -> None:
        """接收Tick数据并更新所有周期"""
        if not self._realtime_enabled or not self._bg_1m:
            return
        
        # 传递给1分钟BarGenerator，触发级联更新
        self._bg_1m.update_tick(tick)

    def _on_1m_bar(self, bar: BarData) -> None:
        """1分钟K线更新回调"""
        # 更新主图（1分钟K线）
        self._chart.update_bar(bar)
        
        # 传递给大周期BarGenerator
        if self._bg_5m:
            self._bg_5m.update_bar(bar)
        if self._bg_1h:
            self._bg_1h.update_bar(bar)
        if self._bg_4h:
            self._bg_4h.update_bar(bar)

    def _on_5m_bar(self, bar: BarData) -> None:
        """5分钟K线更新回调"""
        if self._manager_5m and self._item_5m:
            self._manager_5m.update_bar(bar)
            self._item_5m.update_bar(bar)
            # 触发图表更新
            candle_plot = self._chart.get_plot("candle")
            candle_plot.update()

    def _on_1h_bar(self, bar: BarData) -> None:
        """1小时K线更新回调"""
        if self._manager_1h and self._item_1h:
            self._manager_1h.update_bar(bar)
            self._item_1h.update_bar(bar)
            # 触发图表更新
            candle_plot = self._chart.get_plot("candle")
            candle_plot.update()

    def _on_4h_bar(self, bar: BarData) -> None:
        """4小时K线更新回调"""
        if self._manager_4h and self._item_4h:
            self._manager_4h.update_bar(bar)
            self._item_4h.update_bar(bar)
            # 触发图表更新
            candle_plot = self._chart.get_plot("candle")
            candle_plot.update()
```

#### 2. 处理周期完成事件

当大周期K线完成时（例如5分钟K线完成），需要：

1. **清除索引缓存**：
```python
def _on_5m_bar(self, bar: BarData) -> None:
    """5分钟K线更新回调"""
    if self._manager_5m and self._item_5m:
        # 如果是新K线（周期完成），清除索引缓存
        if bar.datetime not in self._item_5m._bar_range_cache:
            # 新周期开始，清除旧缓存
            self._item_5m._bar_range_cache.clear()
        
        self._manager_5m.update_bar(bar)
        self._item_5m.update_bar(bar)
```

2. **更新索引映射**：
由于大周期K线跨越多个1分钟索引，当1分钟K线更新时，大周期K线的结束索引可能变化。`CrossIndexCandleItem` 的 `_get_bar_index_range` 方法会自动处理这种情况。

#### 3. 性能优化

1. **批量更新**：
```python
def update_ticks(self, ticks: list[TickData]) -> None:
    """批量更新Tick数据"""
    for tick in ticks:
        self.update_tick(tick)
```

2. **节流更新**：
```python
from vnpy.trader.ui import QtCore

class MultiTimeframeWidget:
    def __init__(self, ...):
        # ... 现有代码 ...
        
        # 节流定时器（每100ms更新一次）
        self._update_timer = QtCore.QTimer()
        self._update_timer.timeout.connect(self._flush_pending_ticks)
        self._update_timer.setInterval(100)  # 100ms
        self._pending_ticks: list[TickData] = []

    def update_tick(self, tick: TickData) -> None:
        """接收Tick数据（节流）"""
        self._pending_ticks.append(tick)
        if not self._update_timer.isActive():
            self._update_timer.start()

    def _flush_pending_ticks(self) -> None:
        """处理待处理的Tick数据"""
        if not self._pending_ticks:
            self._update_timer.stop()
            return
        
        # 只处理最后一个Tick（最新价格）
        latest_tick = self._pending_ticks[-1]
        self._pending_ticks.clear()
        
        # 实际更新
        if self._bg_1m:
            self._bg_1m.update_tick(latest_tick)
```

## 关键挑战和解决方案

### 挑战1：跨索引绘制的实时更新

**问题**：大周期K线跨越多个1分钟索引，当1分钟K线更新时，大周期K线的结束索引会变化。

**解决方案**：
- `CrossIndexCandleItem._get_bar_index_range()` 每次绘制时重新计算索引范围
- 使用缓存机制，但周期完成时清除缓存
- 确保 `base_manager`（1分钟BarManager）始终是最新的

### 挑战2：周期边界判断

**问题**：需要准确判断当前1分钟K线属于哪个大周期。

**解决方案**：
- 使用 `HKFEBarGenerator`，它已经实现了精确的HKFE时间边界判断
- 利用 `period_utils` 中的函数（`get_hkfe_hour_period_start` 等）

### 挑战3：性能优化

**问题**：实时更新频率高，需要保证绘制性能。

**解决方案**：
- 使用节流机制，限制更新频率
- 只更新可见范围内的K线
- 使用QPicture缓存，避免重复绘制

### 挑战4：数据一致性

**问题**：多个周期需要保持数据一致性。

**解决方案**：
- 以1分钟K线为基准，所有大周期都从1分钟K线合成
- 使用级联更新机制，确保更新顺序
- 避免直接从数据库加载大周期K线（实时更新时）
