**F821 错误的说明**：
这些错误是因为类型注解使用了字符串形式的前向引用（如 `"BarData"`, `"Interval"`, `"BarGenerator"`, `"ChartWidget"`）。这是 Python 3.7+ 支持的标准做法，用于解决循环导入或前向引用问题：
- 字符串形式的类型注解在运行时不会被解析
- 这是 Python 类型系统的标准特性
- mypy 等类型检查工具会正确处理这些字符串注解
- 这些不是真正的错误，可以安全忽略
