# CTA回测爆仓问题分析

## 问题现象

在CTA回测中选择MHITrendStrategy后，回测完成但显示：
```
回测中出现爆仓（资金小于等于0），无法计算策略统计指标
```

## 爆仓原因分析

### 1. 回测流程中的资金计算

CTA回测引擎计算资金的公式：
```
每日资金 = 初始资金 + 累计净盈亏
净盈亏 = 交易盈亏 + 持仓盈亏 - 手续费 - 滑点
```

当某一天的资金 ≤ 0 时，系统判定为爆仓。

### 2. 可能的原因

#### 原因1：手续费率过高 ⚠️ **最可能**
- **问题**：手续费率设置不合理，累积成本过高
- **检查位置**：CTA回测界面 → "交易成本" → "手续费"
- **MHImain合约建议**：
  - 正常范围：0.0001 - 0.0003 (万分之一到万分之三)
  - 推荐设置：0.0002 (万分之二)
- **影响**：每次交易都会扣除手续费，频繁交易会快速消耗资金

#### 原因2：滑点设置过大 ⚠️
- **问题**：滑点设置不合理，每次交易都有较大成本
- **检查位置**：CTA回测界面 → "交易成本" → "滑点"
- **MHImain合约建议**：
  - 正常范围：0 - 2个点
  - 推荐设置：0.5 或 1.0 点
- **影响**：每次交易都会扣除滑点成本

#### 原因3：策略交易过于频繁 ⚠️
- **问题**：策略频繁开平仓，累积手续费和滑点成本
- **检查方法**：查看回测日志中的成交记录数量
- **MHITrendStrategy当前设置**：
  - `max_daily_trades = 10` - 每日最多10次交易
  - `trend_filter_window = 50` - 趋势过滤周期较短
  - `min_trend_strength = 0.5%` - 趋势强度要求较低
- **影响**：频繁交易导致成本累积，如果盈利不足以覆盖成本，资金会持续下降

#### 原因4：初始资金不足
- **问题**：初始资金太小，无法承受正常的回撤
- **检查位置**：CTA回测界面 → "基本参数" → "初始资金"
- **MHImain合约保证金要求**：
  - 1手保证金约需：20,000 - 30,000港币
  - 建议初始资金：至少是保证金的3-5倍
  - 推荐设置：200,000 - 500,000港币（更安全）
- **影响**：资金太小，即使小幅度亏损也可能导致爆仓

#### 原因5：ATR止损设置不当
- **问题**：ATR止损倍数太小，止损触发频繁，导致频繁亏损
- **MHITrendStrategy当前设置**：
  - `atr_multiplier = 2.5` - 止损倍数较小
- **影响**：止损太紧，容易触发，频繁的小亏损累积成大亏损
- **建议**：增加到 3.0 或 3.5

#### 原因6：策略在不利市场环境下持续亏损
- **问题**：策略在震荡市场或不利趋势下持续亏损
- **检查方法**：查看回测期间的行情走势
- **影响**：如果策略不适应市场环境，会持续亏损直到爆仓

## 解决方案

### 方案1：调整回测参数（推荐先试这个）

在CTA回测界面调整以下参数：

```
【基本参数】
- 初始资金：500,000 港币（从默认的100万降低，但确保足够安全）

【交易成本】
- 手续费：0.0002 (万分之二)
- 滑点：0.5 或 1.0 点
```

### 方案2：使用安全版本的策略

我已经创建了一个安全版本的策略 `MHITrendStrategySafe`，主要优化：

1. **提高ATR止损倍数**：从2.5提高到3.0
   - 减少止损频率，减少频繁亏损

2. **加强趋势过滤**：
   - `trend_filter_window`: 50 → 60
   - `min_trend_strength`: 0.5% → 1.0%
   - 减少交易频率，只在更明确的趋势下交易

3. **更严格的风控**：
   - `max_daily_trades`: 10 → 5
   - `max_consecutive_losses`: 3 → 2
   - 减少交易次数，更快停止亏损

### 方案3：逐步调试

#### 步骤1：最小化交易成本
```
手续费：0（先测试策略逻辑是否正确）
滑点：0（先测试策略逻辑是否正确）
初始资金：1,000,000（确保有足够资金）
```

如果这样还是爆仓，说明策略逻辑有问题。

#### 步骤2：逐步增加成本
```
手续费：0.0001（万分之一）
滑点：0.5点
```

#### 步骤3：逐步降低初始资金
```
初始资金：500,000
```

找到不爆仓的最大成本承受能力。

## 快速修复步骤

### 立即尝试：

1. **在CTA回测界面，调整参数**：
   - 手续费：改为 `0.0002` 或更小
   - 滑点：改为 `0.5` 或 `1.0`
   - 初始资金：改为 `500,000` 或更多

2. **或者在策略参数中调整**（如果能修改策略参数）：
   - `atr_multiplier`: 2.5 → 3.0
   - `min_trend_strength`: 0.5 → 1.0
   - `max_daily_trades`: 10 → 5

3. **重新运行回测**
