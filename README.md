## 简介

VeighNa是一个基于Python的量化交易开发框架，提供了完整的交易系统开发解决方案。

## 功能特性

- 多接口支持：支持多种交易接口（CTP、富途、IB等）
- 策略开发：提供CTA策略、组合策略等多种策略模板
- 数据管理：支持历史数据下载、管理和回测
- 图表分析：提供实时K线图表和指标分析工具
- 回测引擎：支持策略回测和性能分析

## 安装

### 使用VN Studio（推荐）

安装需要基于3.4.0版本以上的[VN Studio](https://www.vnpy.com)。

### 手动安装

```bash
pip install -e .
```
