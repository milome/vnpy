# 代码复用重构方案

## 现状分析

目前存在代码重复的情况：

### K线图表模块 (`vnpy/trader/ui/widget.py`)
- `_get_period_start()` (3333-3430行) - 周期时间划分
- `_get_hkfe_hour_period_start()` (3432-3509行) - 港期1小时周期划分
- `_get_period_open_price()` (3764-3940行) - 大周期开盘价获取
- `_minute_bars_cache` - 1分钟K线缓存

### DataRecorder模块 (`vnpy_datarecorder/period_utils.py`)
- `get_period_start()` - 周期时间划分（功能相同）
- `get_hkfe_hour_period_start()` - 港期1小时周期划分（功能相同）
- `PeriodOpenPriceHelper.get_period_open_price()` - 大周期开盘价获取（功能相同）
- `_minute_bars_cache` - 1分钟K线缓存（功能相同）

## 重构方案

### 方案1：将工具模块移到 `vnpy/trader/period_utils.py`（推荐）

**优点**：
- 位于核心模块，所有模块都可以使用
- 不依赖特定模块，通用性强
- 符合DRY原则

**步骤**：
1. 将 `vnpy_datarecorder/period_utils.py` 移动到 `vnpy/trader/period_utils.py`
2. 更新 `vnpy/trader/ui/widget.py`，使用通用工具模块
3. 更新 `vnpy_datarecorder/engine.py`，使用通用工具模块
4. 更新导入路径

### 方案2：保持现状，但提取公共接口

**优点**：
- 改动较小
- 各模块保持独立性

**缺点**：
- 仍然存在代码重复
- 维护成本高

```python
    def _get_period_open_price(self, period_start, interval, tick):

        return self.open_price_helper.get_period_open_price(
            period_start,
            interval,
            tick.vt_symbol,
            tick=tick,
            minute_bar_generator=self.bg  # 传递BarGenerator
        )
    
    def on_bar(self, bar):
        """缓存1分钟K线"""
        if bar.interval == Interval.MINUTE:
            self.open_price_helper.cache_minute_bar(bar)
        # ...
```
