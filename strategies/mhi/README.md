# MHI期货交易策略

基于VNPy框架开发的MHI(小恒指期货)量化交易策略系统。

## 项目结构

```
strategies/mhi/
├── __init__.py                 # 策略模块初始化
├── mhi_trend_strategy.py       # 主策略文件
├── strategy_settings.json     # 策略参数配置
├── run_strategy.py            # 策略启动脚本
└── README.md                  # 本文档
```

## 策略概述

### 核心特点

- **趋势跟踪**: 基于双移动平均线(EMA)交叉系统
- **动态止损**: 使用ATR(平均真实波幅)设置自适应止损
- **趋势过滤**: 防止在震荡市场中频繁交易
- **风险控制**: 多层级风险管理系统
- **参数化配置**: 支持多种交易风格配置

### 技术指标

1. **快速移动平均线** (默认: 12周期)
2. **慢速移动平均线** (默认: 26周期)
3. **ATR止损** (默认: 20周期, 2.5倍数)
4. **趋势过滤器** (默认: 50周期)

### 交易逻辑

#### 开仓信号
- **做多**: 快线上穿慢线 + 上升趋势确认
- **做空**: 快线下穿慢线 + 下降趋势确认

#### 平仓信号
- **反向信号**: 移动平均线交叉反转
- **ATR止损**: 价格触及动态止损线
- **风控平仓**: 触发风险控制规则

## 策略配置

### 预设配置

| 配置名称 | 风格 | 快线 | 慢线 | ATR倍数 | 最大交易次数 | 描述 |
|---------|------|------|------|---------|--------------|------|
| Conservative | 保守型 | 10 | 20 | 3.0 | 5 | 稳健交易，风险较低 |
| Balanced | 平衡型 | 12 | 26 | 2.5 | 10 | 默认配置，风险适中 |
| Aggressive | 激进型 | 8 | 18 | 2.0 | 20 | 交易频繁，收益与风险并存 |
| Scalping | 剥头皮 | 5 | 12 | 1.5 | 50 | 短线交易，追求小幅快速获利 |

### 风险控制参数

- **每日最大交易次数**: 防止过度交易
- **最大连续亏损次数**: 连续亏损时暂停交易
- **最小趋势强度**: 避免在无明确趋势时交易
- **ATR止损**: 基于市场波动性的动态止损

## 使用方法

### 1. 在VNPy中手动添加

1. 启动VNPy主程序
2. 连接富途网关
3. 启动CTA策略应用
4. 在策略管理界面添加策略:
   - **策略类名**: `MHITrendStrategy`
   - **vt_symbol**: `MHImain.HKFE`
   - **参数**: 从配置文件中选择合适的设置

### 2. 导入策略模块

```python
from strategies.mhi.mhi_trend_strategy import MHITrendStrategy
```

### 3. 查看策略信息

```bash
cd strategies/mhi
python run_strategy.py
```

## 注意事项

### 交易前准备

1. **环境确认**: 确保富途网关连接正常
2. **合约确认**: 验证MHImain合约可交易
3. **资金管理**: 合理设置交易手数
4. **风险评估**: 了解期货交易风险

### 风险提示

- **市场风险**: 期货交易存在市场波动风险
- **策略风险**: 任何策略都无法保证盈利
- **技术风险**: 系统故障可能影响交易执行
- **流动性风险**: 市场流动性不足时可能影响成交

### 优化建议

1. **参数调优**: 根据历史回测结果优化参数
2. **组合策略**: 考虑与其他策略组合使用
3. **定期评估**: 定期检查策略表现并调整
4. **风控升级**: 根据实际交易情况完善风控规则
