### 🔍 关键技术修复

#### 1. 富途网关历史数据查询修复
**问题**: VNPy DataManager下载MHI历史数据失败
```python
# 修复前 - 硬编码限制
if req.interval != Interval.MINUTE:
    return bars  # 只能查询1分钟数据

# 修复后 - 支持多时间周期
interval_mapping = {
    Interval.MINUTE: KLType.K_1M,
    Interval.DAILY: KLType.K_DAY,
}
futu_ktype = interval_mapping.get(req.interval, KLType.K_1M)
```

#### 2. ArrayManager方法调用修复
**问题**: 策略代码使用了不存在的`sma_array()`方法
```python
# 修复前 - 错误调用
fast_ma_prev = self.am.sma_array(self.fast_window)[-2]

# 修复后 - 正确使用talib
fast_ma_array = talib.SMA(self.am.close_array, self.fast_window)
fast_ma_prev = fast_ma_array[-2]
```

#### 3. 期货合约size配置修复
**问题**: 期货合约乘数设置错误，影响PnL计算
```python
# 修复：根据合约代码设置正确size
if symbol_upper.startswith(('MHI', 'MCH')):
    contract.size = 10  # 小恒指/小国指: 每跳10港币
elif symbol_upper.startswith(('HSI', 'HHI')):
    contract.size = 50  # 大恒指/大国指: 每跳50港币
```

**最佳组合 (F8/S15/ATR3.0/TF20/TS0.1)**:

### 🎯 优化策略建议

基于初步优化结果，建议关注以下参数组合:

**高效参数范围**:
- `fast_window`: 5-12 (较短期均线)
- `slow_window`: 15-20 (中期均线，避免过长)
- `min_trend_strength`: 0.1-0.2 (降低趋势要求)
- `trend_filter_window`: 20-30 (缩短过滤周期)
- `atr_multiplier`: 2.0-3.0 (适中止损)
