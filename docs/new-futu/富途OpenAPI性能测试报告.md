- 确保旧缓存值被正确替换为新值

### 缓存更新机制

当检测到主力合约切换时：
1. `_check_main_contract_switch` 方法会重新调用 `_resolve_main_contract`
2. 如果返回的新合约与缓存中的旧合约不同，会更新缓存
3. 更新方式：直接覆盖旧值（`self.main_contract_mapping[main_symbol] = actual_symbol`）
4. 后续调用会使用新的缓存值，避免重复API调用
