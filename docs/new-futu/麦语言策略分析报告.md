# 麦语言多周期MACD趋势策略分析报告

## 1. 策略概述

这是一个非常复杂的多周期MACD趋势分析策略，包含以下核心特征：

### 1.1 策略类型
- **多周期MACD分析**：使用1分钟、3分钟、5分钟、9分钟、15分钟、25分钟、30分钟、45分钟、60分钟等多个周期
- **趋势跟踪策略**：基于主趋势线（MAINTREND1M）的趋势判断
- **主力资金监控**：通过CONTROLLEVEL指标监控主力资金流向
- **多空状态机**：使用CURRENTTREND变量管理8个不同的交易状态

### 1.2 核心指标
1. **主趋势线**：`MAINTREND1M = EMA(EMA(CLOSE,3),3)`
2. **多周期MACD**：MACD1, MACD3, MACD5, MACD9, MACD15, MACD25, MACD30, MACD45, MACD60
3. **主力监控**：CONTROLLEVEL指标（基于KDJ变形）
4. **布林通道**：300周期布林通道
5. **瀑布线**：PB6瀑布线系统

### 1.3 交易状态
- **多头状态**：4（多）、3.5（多等）、3（多等白）、2（多平等）、1（多平）
- **空头状态**：-4（空）、-3.5（空等）、-3（空等白）、-2（空平等）、-1（空平）

### 2.2 核心算法逻辑

#### 主趋势线计算
```m
MAINTREND1M := EMA(EMA(CLOSE,3),3)  // 双重指数平滑
```

#### 趋势状态判断
```m
ISUPTREND := MAINTREND1M >= REF(MAINTREND1M,5) 
             && MAINTREND1M = HHV(MAINTREND1M, 5) 
             && MAINTREND1M > REF(MAINTREND1M,1) 
             && MAINTREND1M - REF(MAINTREND1M,1) >= 0.618 
             && CLOSE > HV(CLOSE, 3);
```

#### 主力监控指标
```m
B1 := (HHV(H,N)-C)/(HHV(H,N)-LLV(LOW,N))*100- M;
B2 := SMA(B1,N,1)+100;
B3 := (C-LLV(L,N))/(HHV(H,N)- LLV(L,N))*100;
B4 := SMA(B3,3,1);
B5 := SMA(B4,3,1)+100;
B6 := B5-B2;
CONTROLLEVEL := (IF(B6>N1,B6-N1,0))*2.5;
```
