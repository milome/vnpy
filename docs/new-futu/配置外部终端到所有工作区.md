# 配置外部终端到所有工作区

## 当前情况

`vnpy.code-workspace` 中的配置只对当前工作区生效：

```json
{
  "settings": {
    "terminal.integrated.useExternalTerminal": true,
    "terminal.external.windowsExec": "powershell.exe"
  }
}
```

## 解决方案

### 方案 1：用户级别配置（推荐）⭐

**优点**：一次配置，所有工作区都生效

#### 方法 A：通过 Cursor 界面配置

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `Preferences: Open User Settings (JSON)`
3. 在打开的 `settings.json` 文件中添加：

```json
{
  "terminal.integrated.useExternalTerminal": true,
  "terminal.external.windowsExec": "powershell.exe"
}
```

4. 保存文件

#### 方法 B：直接编辑配置文件

**Windows 路径**：
```
C:\Users\<你的用户名>\AppData\Roaming\Cursor\User\settings.json
```

例如：`C:\Users\milom\AppData\Roaming\Cursor\User\settings.json`

**操作步骤**：
1. 打开上述路径的 `settings.json` 文件
2. 添加以下配置：

```json
{
  "terminal.integrated.useExternalTerminal": true,
  "terminal.external.windowsExec": "powershell.exe"
}
```

3. 保存文件
4. 重启 Cursor

### 方案 2：工作区级别配置

**适用场景**：只想对特定工作区使用外部终端

**操作步骤**：
1. 打开其他工作区的 `.code-workspace` 文件
2. 在 `settings` 部分添加相同配置：

```json
{
  "folders": [
    {
      "path": "."
    }
  ],
  "settings": {
    "terminal.integrated.useExternalTerminal": true,
    "terminal.external.windowsExec": "powershell.exe"
  }
}
```

3. 保存文件

### 方案 3：使用 PowerShell 脚本自动配置

创建一个脚本来自动配置用户级别设置：

```powershell
# configure_cursor_terminal.ps1
$settingsPath = "$env:APPDATA\Cursor\User\settings.json"

# 读取现有配置
if (Test-Path $settingsPath) {
    $settings = Get-Content $settingsPath -Raw | ConvertFrom-Json
} else {
    $settings = @{}
}

# 添加终端配置
$settings | Add-Member -MemberType NoteProperty -Name "terminal.integrated.useExternalTerminal" -Value $true -Force
$settings | Add-Member -MemberType NoteProperty -Name "terminal.external.windowsExec" -Value "powershell.exe" -Force

# 保存配置
$settings | ConvertTo-Json -Depth 10 | Set-Content $settingsPath -Encoding UTF8

Write-Host "配置已添加到用户设置！" -ForegroundColor Green
Write-Host "请重启 Cursor 使配置生效。" -ForegroundColor Yellow
```

## 配置优先级

Cursor 的配置优先级（从高到低）：
1. **工作区设置** (`.code-workspace` 或 `.vscode/settings.json`)
2. **用户设置** (`%APPDATA%\Cursor\User\settings.json`)
3. **默认设置**

如果工作区设置和用户设置都有，**工作区设置会覆盖用户设置**。

## 验证配置

配置完成后，验证方法：

1. **重启 Cursor**
2. 打开任意工作区
3. 按 `` Ctrl+` `` 打开终端
4. 如果弹出**独立的 PowerShell 窗口**，说明配置成功
5. 如果仍在 Cursor 内部显示终端，说明配置未生效

## 推荐方案

**推荐使用方案 1（用户级别配置）**，因为：
- ✅ 一次配置，所有工作区生效
- ✅ 不需要为每个工作区单独配置
- ✅ 新工作区自动继承配置
- ✅ 统一管理，便于维护

## 注意事项

1. **重启 Cursor**：修改用户设置后需要重启 Cursor 才能生效
2. **工作区覆盖**：如果某个工作区有自己的配置，会覆盖用户设置
3. **外部终端窗口**：使用外部终端后，终端会在独立窗口中打开，而不是在 Cursor 内部

## 回退方法

如果不想使用外部终端，可以：

1. **删除用户设置中的配置**，或
2. **设置为 `false`**：
   ```json
   {
     "terminal.integrated.useExternalTerminal": false
   }
   ```
