# 批量XTRD转换工具使用说明

## 工具功能
这个工具可以批量将文华财经WH8的XTRD格式麦语言文件转换为Python策略文件，支持：
- ZIP文件批量处理
- 目录批量处理  
- 自动依赖关系解析
- 拓扑排序确定转换顺序
- 生成VNPy兼容的策略类

## 使用方法

### 方法1：直接运行工具
```bash
python batch_xtrd_converter.py
```

然后按提示选择：
1. 转换ZIP文件 - 输入ZIP文件完整路径
2. 转换目录 - 输入包含XTRD文件的目录路径
3. 退出

### 方法2：编程方式使用
```python
from batch_xtrd_converter import BatchXTRDConverter

# 创建转换器
converter = BatchXTRDConverter(output_dir="my_strategies")

# 转换ZIP文件
results = converter.convert_zip_file("path/to/your/strategies.zip")

# 或转换目录
results = converter.convert_directory("path/to/xtrd/files")

# 查看结果
for original_file, converted_file in results.items():
    print(f"{original_file} -> {converted_file}")
```

## 输出结果
转换后的Python文件将保存在`converted_strategies`目录中，包含：
- 完整的VNPy策略类结构
- 技术指标计算框架
- 依赖关系注释
- 原始麦语言逻辑的转换模板

## 注意事项
1. **手动调整**：由于麦语言逻辑复杂，转换后的Python代码需要手动调整具体的策略逻辑
2. **依赖安装**：确保安装了必要的Python包：
   ```bash
   pip install numpy talib vnpy_ctastrategy
   ```
3. **编码问题**：工具会自动尝试UTF-8和GBK编码
4. **文件命名**：输出的Python文件名会根据原XTRD文件名自动生成

## 支持的麦语言特性
- ✅ VARIABLE变量定义
- ✅ #IMPORT导入语句
- ✅ 基础技术指标函数
- ✅ 条件逻辑结构
- ⚠️ 绘图函数（需手动调整）
- ⚠️ 复杂嵌套逻辑（需手动优化）

## 故障排除
如果遇到问题，请检查：
1. XTRD文件格式是否正确
2. ZIP文件是否损坏
3. 文件路径是否存在
4. 是否有足够的磁盘空间
5. Python环境是否正确配置
