# 画线下单功能实现总结

## 概述

本文档总结了画线下单功能的完整实现，包括核心功能、技术实现、问题修复和未来改进方向。

## 功能特性

### 1. 画线下单核心功能

#### 1.1 基本功能
- **画线创建挂单**：在图表上点击价格位置，弹出下单对话框，确认后创建挂单线
- **条件触发下单**：挂单线创建后不立即下单，等待价格突破挂单线时自动触发下单
- **价格突破监控**：实时监控价格变化，当价格突破挂单线时自动提交限价单

#### 1.2 止损止盈功能
- **按点数设置**：支持按合约最小变动单位的整数倍设置止损和止盈（如50点）
- **自动生成线条**：设置止损/止盈后，自动在图表上生成对应的止损线和止盈线
- **价格自动计算**：根据挂单价格、方向、点数和最小变动单位自动计算止损/止盈价格
- **颜色区分**：止损线显示为橙色，止盈线显示为绿色，便于区分

#### 1.3 价格线交互功能
- **拖拽挂单线**：支持鼠标拖拽挂单线调整价格，止损线和止盈线自动跟随移动
- **拖拽止损/止盈线**：支持单独拖拽止损线或止盈线，自动重新计算并保存点数
- **双击删除**：双击挂单线弹出确认对话框，确认后删除挂单线及其关联的止损/止盈线
- **联动更新**：拖拽挂单线时，止损线和止盈线保持相对距离跟随移动

### 2. 价格精度支持

#### 2.1 动态价格精度
- **FUTU API查询**：从FUTU API查询合约的`price_tick`，自动计算价格精度
- **整数显示**：对于MHImain等整数价格合约，自动设置为整数显示（无小数点）
- **小数精度**：对于需要小数的合约，根据`price_tick`自动计算小数位数（最多4位）

#### 2.2 价格格式化
- **标签显示**：价格线标签根据价格精度自动格式化显示
- **对话框显示**：下单对话框中的价格显示也遵循价格精度规则

### 3. 主力合约提前切换检测

#### 3.1 检测逻辑
- **初始化检查**：连接初始化时检查当前主力合约是否为提前切换状态
- **仅检查一次**：提前切换检查仅在连接初始化时执行一次，避免重复提示
- **日期比较**：比较当前日期与主力合约月份，如果当前日期早于合约月份，判定为提前切换

#### 3.2 事件通知
- **Toast通知**：检测到提前切换时，在主窗口显示Toast通知
- **状态栏提示**：在状态栏显示提前切换警告信息
- **事件机制**：通过事件引擎发送`EVENT_MAIN_CONTRACT_SWITCH`事件，通知UI更新

## 技术实现

### 1. 核心模块

#### 1.1 `vnpy/chart/order_dialog.py`
- **功能**：画线下单确认对话框
- **主要特性**：
  - 支持设置方向、数量、开平仓
  - 支持按点数设置止损和止盈
  - 实时显示计算后的止损/止盈价格
  - 支持价格精度格式化显示

#### 1.2 `vnpy/chart/price_line.py`
- **功能**：价格线管理
- **主要特性**：
  - `PriceLineItem`：自定义价格线类，继承自`pyqtgraph.InfiniteLine`
  - `PriceLineManager`：价格线管理器，负责创建、删除、查询价格线
  - 支持多种价格线类型：挂单、入场、止损、止盈、预览
  - 支持价格精度设置和标签格式化

#### 1.3 `vnpy/chart/drawing_order.py`
- **功能**：画线下单控制器
- **主要特性**：
  - `DrawingOrderController`：管理画线下单模式
  - 预览线显示：鼠标移动时显示预览线
  - 挂单参数存储：存储挂单参数，等待价格突破时使用
  - 关联关系管理：管理挂单线与止损/止盈线的关联关系

#### 1.4 `vnpy/chart/price_breakthrough.py`
- **功能**：价格突破监控
- **主要特性**：
  - `PriceBreakthroughMonitor`：监控价格突破
  - 注册价格线：注册需要监控的价格线及其回调函数
  - 实时监控：接收tick数据，检测价格是否突破注册的价格线
  - 触发回调：价格突破时调用注册的回调函数

#### 1.5 `vnpy/chart/widget.py`
- **功能**：图表组件
- **主要特性**：
  - 鼠标事件处理：处理画线点击、拖拽、双击等事件
  - 价格线拖拽：实现价格线的拖拽功能
  - 关联线更新：拖拽挂单线时更新关联的止损/止盈线
  - 点数重算：拖拽止损/止盈线时重新计算并保存点数

#### 1.6 `vnpy/trader/ui/widget.py`
- **功能**：主交易界面
- **主要特性**：
  - `ChartWindow`：图表窗口，集成画线下单功能
  - `_on_drawing_click`：处理画线点击事件，显示下单对话框
  - `_create_pending_order_line`：创建挂单线，注册到价格突破监控
  - `_on_price_breakthrough`：价格突破时触发，提交实际订单
  - `process_tick_event`：处理tick事件，更新价格突破监控

#### 1.7 `vnpy_futu/vnpy_futu/futu_gateway.py`
- **功能**：富途网关
- **主要特性**：
  - `_check_main_contract_switch`：检查主力合约切换
  - `_is_early_switch`：判断是否提前切换
  - 初始化检查：连接初始化时检查提前切换，仅检查一次
  - 事件触发：检测到提前切换时触发`EVENT_MAIN_CONTRACT_SWITCH`事件

#### 1.8 `vnpy/trader/ui/mainwindow.py`
- **功能**：主窗口
- **主要特性**：
  - `process_main_contract_switch`：处理主力合约切换事件
  - Toast通知：显示提前切换Toast通知
  - 状态栏更新：更新状态栏显示提前切换警告

### 2. 数据流

#### 2.1 画线下单流程
```
用户点击图表 → _on_drawing_click → OrderDialog → 用户确认 → _create_pending_order_line 
→ 创建挂单线 → 注册到PriceBreakthroughMonitor → 等待价格突破 → _on_price_breakthrough 
→ 提交订单 → 订单成交
```

#### 2.2 价格突破监控流程
```
Tick事件 → process_tick_event → PriceBreakthroughMonitor.update_tick 
→ 检测价格突破 → 触发回调 → _on_price_breakthrough → 提交订单
```

#### 2.3 主力合约切换检测流程
```
连接初始化 → _check_main_contract_switch → _is_early_switch 
→ 检测到提前切换 → on_main_contract_switch → EVENT_MAIN_CONTRACT_SWITCH 
→ process_main_contract_switch → 显示Toast和状态栏提示
```

### 3. 关键技术点

#### 3.1 价格突破检测算法
- 使用`PriceBreakthroughMonitor`实时监控价格变化
- 对于做多挂单：检测价格是否上涨突破挂单价格
- 对于做空挂单：检测价格是否下跌突破挂单价格
- 使用回调函数机制，解耦监控逻辑和订单提交逻辑

#### 3.2 价格线拖拽实现
- 使用`PriceLineDragHandler`管理拖拽状态
- 在`mousePressEvent`中检测是否点击了可拖拽的价格线
- 在`mouseMoveEvent`中更新价格线位置
- 在`mouseReleaseEvent`中完成拖拽，更新关联线条

#### 3.3 关联线条联动
- 使用`_pending_line_relations`存储挂单线与止损/止盈线的关联关系
- 拖拽挂单线时，根据保存的点数重新计算止损/止盈价格
- 拖拽止损/止盈线时，重新计算并保存点数，保持相对距离

#### 3.4 价格精度计算
- 从FUTU API查询`price_tick`
- 如果`price_tick >= 1.0`，设置为整数显示（精度为0）
- 如果`price_tick < 1.0`，计算小数位数（最多4位）
- 价格线标签和对话框都使用统一的价格精度

## 问题修复

### 1. 初始错误修复

#### 1.1 AttributeError: 'DrawingOrderController' object has no attribute '_on_order_event'
- **问题**：方法名错误
- **修复**：改为调用`update_line_from_order`方法

#### 1.2 TypeError: ChartWidget.add_price_line() got an unexpected keyword argument 'order_id'
- **问题**：API变更，不再支持`order_id`参数
- **修复**：使用`DrawingOrderController.create_pending_order_line()`和`link_line_to_order()`方法

#### 1.3 AttributeError: 'PriceLineItem' object has no attribute 'setLabel'
- **问题**：`pg.InfiniteLine`没有`setLabel`方法
- **修复**：使用`self.label.setText()`更新标签文本

### 2. 功能实现问题修复

#### 2.1 止损/止盈线未生成
- **问题**：方向参数传递错误，传递了`Direction`枚举对象而非字符串
- **修复**：使用`direction.value`获取字符串值

#### 2.2 挂单线无法拖拽
- **问题**：鼠标事件处理顺序错误，画线模式优先于拖拽检测
- **修复**：调整事件处理顺序，优先检测可拖拽的价格线

#### 2.3 双击删除未触发确认对话框
- **问题**：双击事件处理逻辑不完整
- **修复**：添加确认对话框，删除挂单线及其关联的止损/止盈线

#### 2.4 止损/止盈线颜色相同
- **问题**：使用方向颜色，导致止损和止盈线颜色相同
- **修复**：在`_create_pen`中为止损线和止盈线设置特定颜色（橙色和绿色）

#### 2.5 删除挂单线时未删除关联线条
- **问题**：只删除了挂单线，未删除关联的止损/止盈线
- **修复**：使用`_pending_line_relations`存储关联关系，删除时一并删除

#### 2.6 拖拽挂单线时止损/止盈线未跟随
- **问题**：未实现关联线条的联动更新
- **修复**：实现`_update_related_lines_on_drag`方法，拖拽时更新关联线条位置

#### 2.7 止损/止盈价格计算错误
- **问题**：使用了合约乘数（size）而非最小变动单位（pricetick）
- **修复**：改为使用`pricetick`计算价格，`size`仅用于盈亏计算

#### 2.8 价格精度问题
- **问题**：MHImain应显示为整数，但显示了小数
- **修复**：从FUTU API查询`price_tick`，自动计算价格精度

#### 2.9 dialog未定义错误
- **问题**：在`_create_pending_order_line`中访问了未定义的`dialog`对象
- **修复**：在`OrderDialog.get_order_params()`中返回`price_precision`，从`params`中获取

#### 2.10 连接初始化时未检出提前切换
- **问题**：如果`main_contract_mapping`在订阅时被预初始化，`old_actual_symbol`不为None，导致跳过初始化检查
- **修复**：添加`main_contract_initialized`集合跟踪已检查的合约，确保初始化时检查提前切换

## 使用说明

### 1. 启用画线下单模式

1. 打开图表窗口
2. 点击"画线下单"按钮，按钮变为绿色表示已启用
3. 在图表上点击价格位置，弹出下单对话框

### 2. 创建挂单

1. 在下单对话框中选择方向（多/空）、数量、开平仓
2. （可选）勾选"设置止损"，输入止损点数（如50点）
3. （可选）勾选"设置止盈"，输入止盈点数（如100点）
4. 点击"确认"按钮，创建挂单线

### 3. 管理挂单线

- **拖拽调整价格**：鼠标左键按住挂单线，拖拽到新价格位置
- **删除挂单线**：双击挂单线，弹出确认对话框，确认后删除
- **查看止损/止盈**：挂单线下方显示橙色止损线和绿色止盈线

### 4. 价格突破触发

- 当市场价格突破挂单线时，自动提交限价单
- 订单提交后，挂单线变为入场线，显示订单状态

## 已知限制

1. **价格突破检测精度**：基于tick数据，可能存在延迟
2. **并发挂单数量**：未限制同时创建的挂单线数量
3. **订单状态同步**：挂单线状态更新可能存在延迟
4. **价格精度查询**：依赖FUTU API，网络异常时使用默认值
