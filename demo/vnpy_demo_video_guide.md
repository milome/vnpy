## 三、自动化演示脚本

可以创建自动化脚本来辅助演示录制，确保每次演示的一致性：

### 演示脚本示例

创建 `scripts/demo_automation.py` 来执行自动化操作：

```python
"""
VeighNa Demo自动化脚本
用于演示视频录制时的自动化操作
"""
import time
from vnpy.event import EventEngine
from vnpy.trader.engine import MainEngine
from vnpy.trader.ui import MainWindow, create_qapp

def demo_workflow():
    """演示工作流程"""
    
    # 1. 初始化引擎
    event_engine = EventEngine()
    main_engine = MainEngine(event_engine)
    
    # 2. 创建GUI
    qapp = create_qapp()
    main_window = MainWindow(main_engine, event_engine)
    main_window.showMaximized()
    
    # 等待界面加载
    time.sleep(2)
    
    # 3. 自动连接（示例）
    # main_engine.connect(settings, "FUTU")
    # time.sleep(5)
    
    # 4. 自动订阅行情
    # subscribe_req = SubscribeRequest(...)
    # main_engine.subscribe(subscribe_req, "FUTU")
    
    # 5. 运行GUI
    qapp.exec()

if __name__ == "__main__":
    demo_workflow()
```

## 七、注意事项

1. **隐私安全**：
   - 使用模拟账户或演示账户
   - 遮挡真实账号信息
   - 不要暴露API密钥

2. **性能优化**：
   - 录制时关闭不必要的程序
   - 确保系统性能良好
   - 避免卡顿影响观看体验

3. **法律合规**：
   - 明确标注这是演示/教育用途
   - 提醒观众投资风险
   - 不提供投资建议

4. **更新维护**：
   - 定期更新视频以匹配新版本
   - 在视频中标注版本号
   - 提供更新说明
